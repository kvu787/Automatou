# Simplified v2 generation prompts

The eight shared masters were produced with the built-in image generator. Each
request combined this shared specification with one unit description.

## Shared specification

```text
Use case: stylized-concept
Asset type: simplified master for paired 64x64 and 32x32 tactical game sprites
Style/medium: extremely simplified retro pixel art designed first for native 32x32 readability, shown enlarged with crisp square pixels; thick clean near-black outline; flat fills; no antialiasing; no dithering; no gradients; no painterly rendering
Composition/framing: exactly one complete unit, centered, three-quarter top-down tactical view facing down-right, bold silhouette, fully contained with generous transparent padding
Legibility rule: the unit must be instantly recognizable when displayed at exactly 32x32 pixels; use only three to five large value masses and one or two oversized signature features; merge or omit anything too small to read at native size
Lighting/mood: one simple upper-left highlight plane and one simple lower-right shadow plane; no cast shadow and nothing beneath the unit
Color palette: at most 12 flat colors; near-black outline, gunmetal navy, cool gray, cyan energy, and one restrained unit-specific accent
Materials/textures: clean factory-new large surfaces with no surface texture
Constraints: actual transparent background with alpha; hard pixel edges; strong negative space between limbs or appendages; no cropped parts; no environment; no ground tile; no base; no frame; no text; no letters; no numbers; no icons; no UI; no watermark
Avoid: all micro-detail and surface noise, tiny panels, greebles, seams, rivets, bolts, vents, cables, grooves, scratches, rust, wear, tear, damage, dents, chipped paint, dirt, grime, stains, scarring, battle marks, tiny lights, decorative highlights, speckling, haze, blur, glow, photorealism, 3D-render detail, multiple poses, sprite sheet
```

## Unit descriptions

### Scout drone

```text
Primary request: a simplified nimble sci-fi reconnaissance drone
Subject: one compact triangular hovering drone; signature features are two large swept fins and one oversized cyan camera eye; small yellow identification block; no visible weapons; reduce thrusters and armor to large plain shapes
```

### Infantry exosuit

```text
Primary request: a simplified sci-fi infantry exosuit
Subject: one human-scale powered-armor trooper; signature features are a large cyan visor and one chunky short pulse rifle; white armor with one orange identification block; use conventional human proportions and broad simple limbs
```

### Assault mech

```text
Primary request: a simplified heavy sci-fi assault mech
Subject: one broad bipedal combat mech; signature features are enormous squared shoulders and one oversized arm-mounted rotary cannon; one large cyan chest core and one red identification block; massive block legs and a tank-like silhouette
```

### Shield projector
