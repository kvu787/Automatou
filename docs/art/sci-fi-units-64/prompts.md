# Generation prompts

The eight source renders were produced with the built-in image generator. Each
request combined the shared specification below with one unit description.

## Shared specification

```text
Use case: stylized-concept
Asset type: production-ready 2D game unit sprite
Style/medium: true retro pixel art, deliberately hand-pixeled, crisp hard-edged square pixels, no antialiasing, no subpixel details, no painterly texture
Composition/framing: one complete unit only, centered, three-quarter top-down view facing down-right, readable silhouette, unit fills about 52x52 pixels with 6-pixel transparent padding on a 64x64 canvas
Lighting/mood: directional light from upper-left, compact dark contact shadow only if it remains translucent
Color palette: cohesive limited palette shared across the set: gunmetal navy, cool gray, near-black outlines, cyan energy lights, with restrained unit-specific accent color
Constraints: actual transparent background with alpha; exactly one isolated unit; designed to remain legible at native 64x64; no cropped parts; no environment; no ground tile; no frame; no border; no text; no letters; no numbers; no icons; no UI; no watermark
Avoid: smooth vector edges, blur, glow haze, gradients, photorealism, 3D render look, isometric terrain, multiple poses, sprite sheet, decorative particles
```

## Unit descriptions

### Scout drone

```text
Primary request: a nimble sci-fi reconnaissance drone sprite
Subject: compact triangular hovering drone with two swept sensor fins, a single cyan camera eye, tiny side thrusters, light armor, yellow identification accents; clearly small, fast, and unarmed
```

```text

```
